# Staff AI for Windows

Download the latest [Staff AI Windows installer](https://github.com/trystaff/staff-downloads/releases/latest/download/Staff-AI-Setup-x64.exe).

Staff AI brings your AI team to your desktop. Learn more at [trystaff.ai](https://trystaff.ai).

Requires Windows 10 version 2004 or later, a 64-bit compatible processor, internet
access, and a Staff account. Early-access account requirements still apply.

The installer adds Staff AI to your Start menu. Uninstall it from Windows Settings
under Installed apps. SHA-256 checksums are included with each release.

The initial installer is unsigned, so Windows may show an unknown-publisher warning.
Download only from this official repository or trystaff.ai.

This repository distributes installer binaries. It does not contain application source.
