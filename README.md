# Staff AI desktop downloads

Windows and Mac downloads are coming soon. Installers have not been released yet.

Staff AI brings your AI team to your desktop. Learn more at [trystaff.ai](https://trystaff.ai).

Planned support: Windows 10 version 2004 or later on x64-compatible processors,
and macOS 14 or later on Apple Silicon and Intel. Internet access and a Staff
account are required. Early-access account requirements still apply.

Published releases will include installation instructions and SHA-256 checksums.

Download only from this official repository or trystaff.ai when releases become available.

This repository distributes installer binaries. It does not contain application source.
